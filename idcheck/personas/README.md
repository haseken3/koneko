# ko-NeKo IDチェッカー 学生像ペルソナ

## ペルソナ設計3原則

- **生語彙で書く**: 教員側の専門用語を使わず、学生本人が口にする言葉で書く
- **固有名人格化**: 「1年生B」「2年生A」のような層代理ではなく、固有のフルネーム・地域・家族・趣味を持つ1人として描く
- **二段翻訳**: 表層（学生の生語彙）と 内部翻訳（制作者向け中間語）を併記する

## 用途

ko-NeKo IDチェッカーは **教員向けツール**。教員が念頭に置く「対象者レベル評価」のためのペルソナとして使う。学年（1〜4年次）に対応する4人を用意し、UI 側で年次選択 → 対応ペルソナを LLM に渡す。
