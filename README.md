# ko-NeKo

オンデマンド授業教材（PowerPoint）の制作支援ツール群。Streamlit Web アプリとして動作。

## 機能

### 1. 授業資料チェッカー（`app.py`）

PPTX を教員が提出する前にセルフチェックするツール。文字数カウンター＋AIによる2つのチェックの3機能。

**文字数カウンター**（PPTX取り込み時に自動実行）
- ノート欄に書かれたナレーション原稿の文字数をカウントし、想定動画尺を推定する
- スライドごとの文字数・読み上げ時間・句読点ポーズを集計、分あたりの読み上げ文字数を調整可能
- ノート原稿をAIが意味分割し、ステップ（最大4つ）ごとの尺を確認できる（sonnet-5・安価なので自動実行）

**内容の不一致チェック（AI・ボタンで実行）**
- スライド本文とノート欄の原稿を突き合わせ、内容が食い違っている可能性のある箇所（不足・相違・過剰）を提示する
- あくまで「可能性」の提示に留まり、最終判断は教員が行う
- opus-5を使うため（誤検知を抱えるための実測でopus-5が必要と判明）枚数が多いと数分・費用がかかるので、取り込み時の自動実行ではなくボタン押下で実行する

**誤字脱字チェック（AI・ボタンで実行）**
- スライド本文とノート欄の原稿から、誤字・脱字・誤変換の可能性がある箇所を提示する
- こちらも断定はせず、「可能性」の提示に留まる
- 内容の不一致チェックと同時に実行される（同じボタン）

チェック結果はステップ単位でグルーピングして画面に表示し、Word（.docx）でダウンロードできる（サイドバーのダウンロードボタン）。印刷して手元でチェックしながら作業できる形式。

各機能が使用するAIモデルは `llm_models.py` で一元管理（実測に基づき既定値を決定）。教員向け画面には表示しない（先生に見せる情報ではないため）。

### 2. IDチェッカー（`idcheck/idcheck_app.py`）

PPTX をアップロードし、鈴木克明（2006）レイヤーモデル準拠44項目チェックリストで自動評価する。Claude API による評価結果を Word フィードバックとしてダウンロード可能。

📘 **教員の方は [`docs/teacher_guide.md`](docs/teacher_guide.md) を参照してください**（説明書 + 仕様書）

- 学年（1〜4年次）に応じた学生像ペルソナで評価視点を切替
- LLM 評価可能な項目に絞った効率評価
- 評価結果は「要改善 → 中立 → 良好 → 失敗」のスコア別グルーピングで Word 出力
- 評価ペルソナの内部実装は教員に開示せず、年次選択 UI のみ表示

## セットアップ

### 依存関係
```
pip install -r requirements.txt
```

`requirements.txt` には Streamlit / python-pptx / python-docx / anthropic がピン留めされています。

### Anthropic API キー（ステップ分割・内容チェック・IDチェッカー）

ローカル実行時:
```
~/.config/koneko-idcheck/anthropic_api_key.txt
```
に API キーを保存（推奨 `chmod 600`）。

Streamlit Cloud デプロイ時:
- Streamlit Cloud の Secrets 設定で `anthropic_api_key` を設定

## 起動

### 授業資料チェッカー
```
streamlit run app.py
```

### IDチェッカー
```
streamlit run idcheck/idcheck_app.py
```

## ライセンス

Internal use — 開志創造大学情報デザイン学部

## 注意

- IDチェッカーの評価結果は LLM による自動評価であり、教員の最終確認・修正の参考としてご活用ください
- 学年別ペルソナによる評価は「該当学年の代表的な学生像1名」を念頭に置いた視点であり、その学年全体の総意を代表するものではありません
- 内容の不一致チェック・誤字脱字チェックは、いずれも「気づいた点の提示」であり、誤りを保証するものでも、すべての誤りを見つけるものでもありません。最終的な判断は教員が行ってください
